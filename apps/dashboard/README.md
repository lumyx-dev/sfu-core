# `@sightline/dashboard`

The web UI for Sightline — rooms, peers and live media quality at a glance.

> **Scaffold.** This is still the default Next.js starter page. Nothing here talks to the SFU
> yet. The interesting code lives in [`apps/sfu`](../sfu).

## Running it

From the repo root:

```bash
bun install && bun run dev
```

Or just this app:

```bash
bun run dev --filter=@sightline/dashboard
```

Next.js serves on `http://localhost:3000` by default — the same port the SFU uses. Run the
dashboard on another port while both are up:

```bash
bun run dev --filter=@sightline/dashboard -- --port 3001
```

## Stack

Next.js 16 (App Router) · React 19 · Tailwind CSS 4 · TypeScript.

Shared code belongs in [`packages/`](../../packages) — `ui` for components, `env` for validated
environment variables, `db` and `auth` for their respective concerns.

## What it needs to become

The SFU already exposes everything a first useful version requires:

- `GET /metrics` — room count, peer count and throughput counters, polled or streamed
- `GET /health` — liveness

Building on top of that: a room list, a per-peer view, and — once the quality-metrics milestone
lands in the SFU — live jitter, packet loss and RTT charts. See the
[roadmap](../../README.md#roadmap).
